# 线性代数：另一个视角

**从线性映射与几何直觉出发，重构线性代数的知识体系。**
> 本文档基于复旦大学物理学系线性代数课程讲义重排，旨在提供一条从“计算”到“直觉”的学习路径。

## 简介
传统的线性代数教学往往从繁琐的行列式计算开始，而将最能体现数学本质的“线性映射”和“向量空间”置于末尾。本文档通过重新编排知识顺序（**向量语言 → 线性映射 → 矩阵运算 → 行列式 → ... → SVD**），强调“**矩阵即线性映射**”的核心思想，帮助读者建立强烈的几何直觉。

## 知识图谱与学习路径
本文档共分为 **10 个阶段**，遵循严格的逻辑依赖关系：
1.  **阶段 0-2**：建立“矩阵 ≡ 线性映射”的直觉
2.  **阶段 3-4**：讨论“保体积吗？”（行列式）与“可达吗？”（秩与方程）
3.  **阶段 5-6**：抽象收口四大子空间，并引入基变换
4.  **阶段 7**：探索特征值、对角化与 Jordan 标准形
5.  **阶段 8-10**：引入内积、正交、二次型，最终抵达 SVD

## 特色
- **几何直观**：用“保体积”、“压扁”、“可达”等几何语言解释代数概念。
- **为什么驱动**：大量补充了教材中省略的“为什么”（如为什么 \(T(0)=0\) 是推论而非条件）。
- **现代视角**：直接引入 SVD、伪逆、矩阵范数与条件数等数值线性代数核心工具。
